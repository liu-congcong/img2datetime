# img2datetime

Rename images using their creation time.

## Usage

```TEXT
img2datetime v1.0.0
Rename images using their creation time.
https://github.com/liu-congcong/img2datetime

Usage:
  img2datetime [options]

Options:
  -i    Input directory containing the images.
```
